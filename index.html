I build optimization solvers that learn.

Exact methods for truck–drone routing, with the expensive judgement calls (which state to keep, which branch to take, which cut to add) handed to models trained on the problem itself.

Research

My thesis asks how far machine learning can be pushed inside exact combinatorial optimization, using drone routing as the test bed. Four threads run through it, and all of them are evaluated against strong classical baselines (LKH, local search, partition dynamic programming) at matched computational budgets.

  • Generative models for tours

    Operation-level GFlowNets that sample truck–drone tours as sequences of routing operations, and a study of what actually matters in learned pipelines for the TSP with drone: the search objective, start diversity, and learned priors.

  • Learning to compile decision diagrams

    Relaxed decision diagrams give bounds; the bound depends on which states get merged. I train the merge rule directly on bound quality, and work on Bellman-state diagrams for integrated last-mile transportation.

  • Learned decisions inside MILP solvers

    Branching policies trained with proximal policy optimization, and learned cutting-plane selection, both plugged into a standard branch-and-cut loop rather than replacing it.

  • Honest evaluation

    Matched-budget protocols, reproducible instance sets and ablations that separate the contribution of the learned component from the contribution of the search around it.
